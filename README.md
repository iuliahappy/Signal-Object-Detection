# English version
# Signal Object Detection 📡

This repository contains a progressive Machine Learning pipeline designed to classify signal images into 5 distinct categories. 

The project explores multiple approaches, starting from classical baselines (Naive Bayes, SVM with PCA, Random Forest on HOG features) and advancing to heavily optimized, deep Convolutional Neural Networks (CNNs).

# Versiunea în română
# Detecția Obiectelor de Semnal 📡

Acest repository conține un pipeline progresiv de Machine Learning, dezvoltat pentru a clasifica imagini de semnal în 5 categorii distincte. 

Proiectul explorează multiple abordări, pornind de la modele clasice de bază (Naive Bayes, SVM cu PCA, Random Forest pe caracteristici HOG) și avansând către Rețele Neuronale Convoluționale (CNN) profunde și puternic optimizate.
